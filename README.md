# Lime player

This is just a simple project I am making in order to learn and practive JUCE framework. Therefore I'm minimizing my usage of AI for this project.

<img width="814" height="780" alt="Lime player" src="https://github.com/user-attachments/assets/4e5f4195-fd9e-4e97-bcd7-1e748bb7a394" />

It's a player, that can do simple stuff like:
- load a song, play/pause it; 
- visualise, zoom in/out on the waveforms;
- apply different level of gain in left and right channel. 

<img width="600" height="600" alt="Lime player gif" src="https://github.com/user-attachments/assets/2694c7e0-2e5d-4fe1-b9a6-97a6c2248b9d" />

## Plans

It is super simple for now, but I have an ambition of building upon it, and try some voice separation algorythms, so that instead of left/right channels there would be ability to change the gain of voice or accompaniment.
